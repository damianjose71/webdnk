## Hechos conocidos

- DNK **comenzó como productora audiovisual**.
- Está **evolucionando hacia una agencia creativa integral**.
- Ofrece cinco áreas: producción audiovisual, diseño gráfico, branding,
  creación y estrategia de contenido, y desarrollo/creación de páginas web.
- El desarrollo web es un servicio real y de primer nivel, no un añadido.

## Implicación para la web

La página **no** debe plantearse como la de una productora que hace otras
cosas de paso. Desde la arquitectura, DNK se presenta capaz de combinar:

- Estrategia
- Diseño
- Comunicación visual
- Producción audiovisual
- Contenido
- Tecnología y desarrollo web

La estructura de datos y rutas ya lo refleja: cinco servicios con el mismo
peso, cinco rutas propias y navegación simétrica.
